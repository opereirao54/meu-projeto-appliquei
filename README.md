# Página de apoiadores do Flávio — TikTok

Material da página de apoiadores (não oficial) de Flávio Bolsonaro no TikTok.

- `.claude/skills/posts-tiktok-pagina-flavio/SKILL.md` — diretrizes de criação de posts (pesquisa, padrão visual, legendas, limites). É carregada automaticamente quando este repositório está conectado a uma sessão do Claude.
- `scripts/` — scripts Python (Pillow + ffmpeg) que geraram os posts.
- `posts/` — posts já publicados ou prontos (1080×1920).

Os vídeos (MP4) não estão no repositório por tamanho e por conterem trechos da transmissão da TV Band.
